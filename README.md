# 멍멍살롱

> 반려견 카페·클래스 안내 웹사이트 | 웹 디자인·퍼블리싱 / 프론트엔드 포트폴리오

## 프로젝트 소개
반려견과 보호자가 함께 이용하는 카페를 콘셉트로 사이트를 제작했습니다. 카페와 클래스 소개뿐 아니라 방문 정보를 입력하고 확인하는 화면까지 연결했습니다.

## 사용 기술
HTML · CSS · JavaScript · FormData · dialog

## 주요 작업 내용

### 01. 메인 화면
서비스·프로그램·이용 안내·FAQ를 보기 쉽게 나누어 배치했습니다.

### 02. 클래스 소개
반려견 간식 원데이 클래스의 콘텐츠 페이지를 제작했습니다.

### 03. 방문 정보 입력
이름·연락처·날짜·시간·반려견 정보를 받는 폼을 구성했습니다.

### 04. 유효성 검사
필수 항목과 연락처 형식을 확인하고 FormData로 입력값을 모아 모달에 표시했습니다.

### 05. 날짜 및 시간 처리
지난 날짜와 현재 시각 이전 시간대를 선택할 수 없도록 처리했습니다.

### 06. 모바일 메뉴
메뉴 버튼과 Escape 키로 내비게이션을 제어하도록 작성했습니다.

## 작업하면서 익힌 내용
폼 입력값을 검사하고 FormData로 수집한 뒤 dialog에 표시하는 과정에 집중했습니다. 날짜와 시간을 비교하는 JavaScript 로직도 실습했습니다.

## 프로젝트 정리
정보성 페이지에서 사용자 입력 화면까지 확장하면서 폼 처리와 UI 동작을 연습한 작업입니다.
